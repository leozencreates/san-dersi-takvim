# San Dersi Takvim Botu

Telegram botu: gruptaki herkes haftalik musait saatlerini isaretler, bot ortak saatleri bulur,
ders saatini sabitler ve hatirlatir.

- `bot.py` - bot (python-telegram-bot)
- `docs/index.html` - Telegram Mini App (GitHub Pages: https://leozencreates.github.io/san-dersi-takvim/)
- `.env.example` - ayarlar sablonu (`.env` olarak kopyala, BOT_TOKEN yaz)

Kurulum:

    pip install -r requirements.txt
    copy .env.example .env   (token'i yaz)
    start.bat
